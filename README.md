# 🎄 크리스마스 데스크 (Christmas Desk)

크리스마스 장식으로 Windows 바탕화면을 꾸미는 데스크탑 컴패니언입니다. 트리와 가랜드를 달고, 창 위에 눈이 쌓이고, 쌓인 눈으로 눈사람을 만들 수 있어요.

## 다운로드

| 파일 | 설명 |
|------|------|
| [**XmasDesk-standalone.exe**](https://github.com/Studio-Nebbiolo/XmasDesk-Build/raw/main/XmasDesk-standalone.exe) | **추천.** 받아서 바로 실행하면 됩니다 (약 70MB) |
| [XmasDesk.exe](https://github.com/Studio-Nebbiolo/XmasDesk-Build/raw/main/XmasDesk.exe) | 경량판. [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)을 먼저 설치해야 합니다 |

- Windows 10 / 11 (64비트)
- 설치 과정 없이 exe를 실행하면 끝입니다.
- 서명되지 않은 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.
- 실행하면 작업표시줄 오른쪽 트레이(^ 안쪽)에 트리 아이콘이 생깁니다. **아이콘을 우클릭**하면 모든 기능이 나옵니다.

## 할 수 있는 것

- **트리 설치**: 트레이 메뉴 → 트리 설치. 트리는 작업표시줄 위에 서고 좌우로 옮길 수 있어요. 스타일: 클래식 / 눈 덮인 / 실버 / 핑크
- **오너먼트 꾸미기**: 트리 우클릭 → 오너먼트로 꾸미기 → 팔레트에서 원하는 자리로 끌어다 놓기
- **조명 줄**: 트리 우클릭 → 조명 줄 달기, LED 색상과 반짝임 패턴 설정
- **가랜드**: 트레이 메뉴 → 가랜드 설치 → 시작점에서 끝점까지 드래그. 솔잎 / 금빛 틴셀 / 깃발 / 전구
- **쌓이는 눈**: 창 윗변과 작업표시줄 위에 눈이 쌓이고, 창을 움직이면 눈이 떨어져요. 전체화면 앱에는 쌓이지 않아요
- **눈사람**: **Ctrl을 누른 채 쌓인 눈을 끌면** 눈덩이가 생기고, 눈 위로 굴리면 커져요. 다른 눈덩이 위에 올리면 눈사람! 우클릭 → 얼굴 꾸미기

## 업무 · 게임 방해 금지

- 장식 모양 바로 위에서만 마우스가 반응하고, 나머지는 클릭이 그대로 통과합니다.
- 전체화면 게임이나 영상에서는 자동으로 숨겨집니다.
- **Ctrl + Alt + Shift + X** 또는 트레이 아이콘 더블클릭: 모두 숨기기 / 보이기
- 트레이 메뉴 → **장식 잠금**: 모든 장식이 클릭을 통과
- 모든 기능은 트레이 메뉴에서 켜고 끌 수 있어요.

## 지우기

트레이 메뉴 → 종료 후 exe 파일을 지우면 됩니다. 설정은 `%APPDATA%\XmasDesk` 폴더에 있습니다.
